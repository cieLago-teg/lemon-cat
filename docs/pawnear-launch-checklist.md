## 已实现的代码

- 网页标题和账户入口改为 Pawnear · 爪伴，保留原 Cookie、数据库、仓库名，避免改名使已有登录和宠物失效。
- 公开邮箱注册的独立开关、验证邮件、找回密码、30 分钟一次性令牌、密码设置后所有旧会话失效。令牌只存 SHA-256；链接放 URL fragment，确认页读取后清除地址栏令牌；不会被邮件扫描器的 GET 请求消费。

- 失败/结果不明的运营费用预留不会自动退款。跨月未核销预留仍占预算，防止旧任务在下个月收费却被漏计。`settled_micros` 留给供应商实际账单核销；本轮不提供自动核销或伪造实际成本。
- 任务恢复页和可选形象评分中英文，注册/找回/确认页中英文；保留评分值和用户输入。
- Next.js 15.5.25、Undici 8.10.2、Sharp 0.35.4、PostCSS 8.5.28，以及安全传递依赖锁定；新增 Nodemailer 10.0.3。未跳到 Next.js 16。
- `npm run dev` 先检查显式端口，端口占用时在启动 worker 前退出；避免 Next 自动换端口后多个进程共用 `.next` 缓存。本轮已清理确认属于本项目的重复进程，未删除缓存或数据库。不要在运行 dev 时向同一个 `.next` 执行生产构建。

## 需要 Dear cieLago 操作 / 决定

1. **先确认品牌风险，暂不买域名。** Google Play 已有同名宠物应用 [PawNear](https://play.google.com/store/apps/details?id=com.petrichor.pawnear)，做走失宠物寻找。搜索不是商标结论，但足以要求公开使用前复核；我不能替你声称名称无冲突。需要决定接受进一步检索还是换名。域名注册可用性、首年及续费报价尚未确认。
2. **恢复本机 Docker。** 启动日志显示 `Docker/run/dockerInference` 残留通信文件无法访问；0 字节重解析文件，保留备份的重命名也失败。请在方便时先保存其他工作，退出 Docker 后重启 Windows，再启动 Docker Desktop。不要点“Reset to factory defaults”。如果仍失败，把错误文本给我，我继续定位；不需要你重建宠物数据库。
3. **确认花钱前的预算分配。** 总额仍是域名 ≤300 元/年、云与 AI 合计 ≤300 元/月。建议暂按云 150、AI 100、缓冲 50 测算，但没有将这些数值写入运行配置。需要实际同规格续费报价装得下再购买；不默认开通自动续费、超额付费或升级配置。
4. **在自己的阿里云账号完成实名与最终购买确认。** 暂优先比较香港 `cn-hongkong` 与新加坡 `ap-southeast-1` 的 2 核 / 4GB、系统盘、备份和普通流量同口径报价；这是待压测规格，不是已验证能承载多少用户。不要为了首月优惠忽视续费。你只负责账号所有权、实名认证和最终付款；部署命令、DNS/HTTPS 配置我可以在获得适当访问后做。
5. **最终域名选定后完成持有者认证。** 只买一个主域名；`.com/.app/.pet` 均可，避开溢价和续费超预算。只向聊天发送域名和非敏感报价；身份证、密码、验证码不要发送。官网：[注册流程](https://help.aliyun.com/zh/dws/user-guide/how-to-register-a-domain-name)、[价格说明](https://help.aliyun.com/zh/dws/product-overview/domain-name-fees)。
6. **在控制台配置发信与模型授权。** 需要事务邮件 SMTP 及发信域名验证、私有 OSS Bucket、最小权限 RAM、DashScope 工作空间。凭证只进入服务器环境变量或密钥管理，不进 Git 或聊天。是否真实收得到验证与重置邮件，最后需要你用自己的邮箱确认一次。
7. **最终人工验收与公开许可。** 从校园/家庭网络上传你熟悉的宠物照片，完成一次获授权的真实付费生成，在你自己的 Windows 桌面确认能播放、关闭后能恢复。确认实际效果、账单、数据披露和待修问题后，再授权开放注册。不接支付、不宣称商业化已经具备条件。

## 成本配置说明

`.env.example` 只列变量，不包含密钥或未经确认的费用。`AI_MONTHLY_LIMIT_MICROS=100000000` **表示 100 元，仅是单位示例，不是已授权配置**。

`AI_CALL_LIMITS_JSON` 将完整的调用规格标识映射到每次调用的保守最大费用；标识由 worker 中 `reserveCall` 的参数组成。图像是 1024×1024、n=1；视频包括实际 `buildPetVideoRequest().parameters`。识别要覆盖最大合法图片输入和 768 输出 token。切换模型/地域后必须重新核价，不能复制别的地域价格。

该闸门保证应用按已配置上限原子准入，不能保证供应商未来涨价、其他程序共用 Key 的消费、云主机/流量或账单延迟永远不超额。模型实验脚本 `models:inspect --paid` 不走线上 worker 预算，不应使用生产 Key。上线应单独工作空间/Key，并配合阿里云费用报警与带宽上限。

## 新发现的发布风险

- [Next.js 官方安全通告](https://github.com/vercel/next.js/security/advisories/GHSA-p293-qw3h-jr36)涉及 Windows 托管应用的未认证代码执行；本轮已更新到修复版本。不能长期运行升级前尚未重启的进程。
- 仓库部分抠图路径使用 RMBG-1.4，视频逐帧抠图也可能进入该模型；[模型方说明](https://huggingface.co/briaai/RMBG-1.4)为非商业许可，商业使用需单独协议。不能因为产品“先免费”就默认商业许可无关。上线前应禁用未获授权路径或选择经验证的可用方案，不自动购买许可。
- 同一域名可指向香港或新加坡，不要求机房和品牌一起更换。CDT/OSS 的流量计费不是一回事，实际同规格报价和校园线路实测仍待完成。
