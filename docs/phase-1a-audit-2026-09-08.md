# 1A 复核与补齐记录

日期：2026-09-08。范围：TRAE Work 接续后的 1A 稳定性、安全边界、持久任务与桌面交付；不进入 1C，不创建云资源，不调用付费模型。

## 结论

TRAE 的登录和日志工作有实际价值，但不能据此判定 1A 高质量完成：当时注册页面没有邀请码字段、任务只检查登录未检查归属、私有响应允许共享缓存、宠物仍写 JSON、动画仍是进程内任务，网页服务器还承担启动 Electron 的职责。本批把这些主干问题接入实际持久化链路。

这是一份本地封闭验收交付，不是“可以公开收费上线”的证明。下面将已完成实现和仍需外部验收的部分分开。

## Changed：本批实现

- 登录错误原地可见；注册补邀请码；限制返回地址，所有写入统一检查 Origin/JSON/请求大小，所有 API 响应强制 private/no-store，请求 ID 由服务端生成。
- 宠物 CRUD 使用 PostgreSQL，所有档案、任务、素材读取及修改按本人归属校验；并发编辑用版本条件更新，冲突返回 409。17 份旧档案已备份并导入，原始素材保留。
- 识别、生图、动画先持久化任务、预留内测额度，再由独立 worker 处理。相同幂等键只建一次；相同输入的未完结/待核对任务也复用；每人最多三个活跃任务。
- worker 租约抢占与续租、保存上游 ID、只查询原任务恢复；提交结果不确定时停在 `needs_review`，不盲目重提。明确失败退还一次内测额度；不确定状态保留额度等待核对。
- 新图片与视频保存为本人私有资产，支持本地目录或 S3；校验大小和 SHA-256，视频支持 Range。使用临时签名链接让供应商读取 S3 参考图；旧本地资产可按需复制到 S3。
- 生图成功后可在 `/tasks` 找回并保存档案；动画完成时直接写回匹配的本人档案，不依赖网页继续开着。
- 统一 `app-shell` IPC：只接受主页面同源调用和受限私有资产地址，下载校验 WebM 后在沙箱透明窗口播放；保存离线缓存并校验恢复。网页端只预览。旧本地 WebM 按需转私有资产，不重新生成；旧文件不删除。
- `npm run dev` 同时启动 web/worker；修复 start 的服务环境加载、lint 命令，固定桌面依赖并新增 lock。旧 PowerShell 隔离测试复用当前 HTTP 验收，不再读取真实旧账号密码或写死 17 条预期。

## Verified：验收方法与证据

本批测试全部使用本地 PostgreSQL、独立测试账号和合成素材，没有调用付费生成。

```powershell
npm run migrate
npm run build
npm run check
npm run check:service
# 另开两个终端：npm run start / npm run worker
npm run check:http
npm run check:desktop
```

- `check`：类型检查与本地回归；数据库专项在未配置独立测试地址时主动跳过，由 `check:service` 单独执行。
- `check:service`：真实 PostgreSQL 隔离 schema，覆盖并发去重、余额不足、租约隔离、退额一次、档案归属与并发冲突；子进程记录上游 ID 后以退出码 17 直接退出，新 worker 恢复时断言上游提交次数仍为 0。
- `check:http`：运行中的生产构建，双账号交叉 GET/PATCH/DELETE/动画/私有素材隔离，CSRF、缓存策略、Range、额度为 0 不提交、退出后会话失效，以及旧 WebM 按需私有化。
- `check:desktop`：实际 Electron 运行统一桌宠模块，检查视频尺寸、播放时钟、静音和循环；canvas 像素断言前景可见、背景 alpha=0；新进程拦截全部 HTTP/HTTPS 后，仍从缓存恢复并通过相同断言。
- 桌面截图：`output/playwright/desktop-online.png` 与 `desktop-offline.png`。红色方块是明确标注的合成验收素材，不是宠物生成质量证据。
- Windows unpacked 应用构建成功，`app-shell/dist/win-unpacked/柠檬猫.exe`；已检查 ASAR 包含桌宠 HTML/preload/renderer/IPC 与 pino。不是已签名安装包，不等同于打包入口全链路验收。
- 本地回归结果：73 通过、1 项数据库测试按设计跳过；`check:service` 独立执行通过；生产 HTTP 32 项检查通过。lint 无错误，但仍有历史未使用变量、原生 img 等警告，不称为零警告交付。
- Playwright 实点 `/tasks` → 填写合成素材档案名 → 保存 → `/create/success?id=…` 显示新档案，再点击退出回到登录页；退出后的 `/api/auth/me` 返回预期 401。新鲜截图 `output/playwright/phase1a-recovered.png`。390×844 注册页邀请码和创建按钮可见，截图 `phase1a-register-mobile.png`；视觉验收由 Playwright 技能的快照→交互→重新截图流程完成。
- 桌面测试在受限执行环境中曾报 GPU 子进程 DLL 加载失败（`-1073741515`）；相同代码在正常 Windows 权限下在线/离线均通过，没有通过关闭校验来掩盖失败。
- 没有配置模型 Key 时，编译后的供应商模块仍可加载；鉴权检查移到真正调用时，避免未填 Key 就导致整个 worker 无法启动。
- 提交钩子发现常规 lint 漏掉桌面源码；已把 `app-shell` 纳入日常检查，并为该目录实际使用的 CommonJS 文件设置匹配规则，提交钩子继续启用。

## Remaining risk：公开上线前仍须完成

1. **真实云端链路**：尚未提供并验收实际私有 S3 桶、部署目标、持久卷、域名/TLS、数据库备份恢复、云端 worker 模型/FFmpeg 环境。`/health` 的 `local_only` 不能当成云存储通过；`railwayAssetPipelineVerified` 明确为 false。
2. **实际模型与预算**：真实照片识别→四风格→Wan→抠像→本人客户端下载未进行付费验收。默认额度 0；维护者需确认预算后配置受控内测额度。1/4/10 是内部额度单位，不是人民币。尚无支付、充值/退款后台或 `needs_review` 自助核对工具。
3. **生图中断边界**：四种风格逐张提交，一组中途断线时保守转待核对，不重提整组；当前没有逐风格持久检查点或供应商侧可证明的 exactly-once，不能承诺所有断点自动恢复。
4. **身份保真和成品质量**：当前风格化生图主要基于识别文字，并非已验收的原照片参考图保真流程；真实宠物相似度、循环接缝、毛发抠像、不同显卡与屏幕行为需要照片样本实测。旧 MP4 仅网页预览，透明桌宠需要合格 WebM。
5. **发行与商业边界**：Electron 32.3.3 是继承并锁定的旧运行时，公开发行前需升级到受支持版本并回归、代码签名和安装/卸载验收。模型/素材商用许可、隐私条款、删除/导出流程、滥用防护与运营支持尚待上线专项确认。
6. **数据维护**：旧 JSON/媒体、测试专用 schema/账号/素材、worker 工作目录按保护数据原则保留，没有批量清理；后续应在确认备份后制定有范围的回收策略。删除档案当前只移除数据库记录，素材仍保留以便恢复。
