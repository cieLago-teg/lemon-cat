## 已确认的边界

- 阿里云海外地域，优先比较中国香港与新加坡；开放邮箱注册，网页中英双语 + Windows 桌宠。
- 每账户每日最多 3 次完整创建，额外主动重生成占次数；另设全站 AI 预算硬闸。每日次数是个人上限，不承诺全站预算耗尽后仍可生成。
- 免费、不接支付；依据实际使用与留存，再决定支付和扩容。
- 域名注册和续费均不超过 300 元/年；云资源与 AI 合计不超过 300 元/月。已有阿里云账号，尚无域名。
- 初步测算分配：基础云资源 150 元/月、AI 100 元/月、缓冲 50 元/月，不是已购买报价或已启用的运行配置。报价装不下时先调整方案，不自行加预算。
- 品牌优先，可接受 `.app` / `.pet` 等后缀。已选择爪伴 / Pawnear 作为工作品牌；检索发现同名宠物应用，公开使用前需进一步复核，尚未购买域名。

### AI 硬闸不是余额报警

每次外部付费调用之前，在数据库中原子预留该调用的最大可计费额度；同时检查账户机会与全站日/月预算。禁止把并发任务仅在完成后扣账。价格按模型、地域、分辨率、时长和版本记录；识别输入/输出 token 也需要上限。没有价格或无法界定调用成本时拒绝新调用。

已经成功计费或结果不明的调用保留费用预留，不能因为给用户退机会就退掉运营成本。重试必须重新评估预算，先查询已提交任务；幂等重放不新扣机会。到达预算时拒绝新生成，仍允许访问、下载已保存的宠物。预留额、实际账单和余额报警互相核对；供应商价格变化及云账单延迟仍需留缓冲，不能把应用估价称为供应商结算绝对保证。

100 元 AI 预算按前一份文档的北京默认图像/视频参考价，理论上约 74 只/月；计入识别、失败、重生成或国际地域价格后更少。故此预算适合验证少量真实用户，不适合承诺无限人数每天免费三只。云资源超额流量不受 AI 闸门保护，需要独立带宽上限、请求限流和费用监控。

## 指标定义 v1（待埋点，无真实基线）

目标：验证自己的宠物是否让用户愿意持续使用。第一主指标是激活后的回访，辅以真实桌宠启动；上传/生成用于解释漏斗损失，成本作为硬约束，分享为次级信号。候选 D7 留存保留为后续观察，注册总数、页面浏览数不作为成功替代。

统一记录 UTC 时间；指标采用首次激活后的相对时间窗口，避免各国午夜错位。后台明确显示统计时区和版本，不能与“每日三次”的产品日界线混淆。所有比率显示分子、分母和未知/观察中数量；分母为零显示“暂无数据”。排除维护者、本地开发、自动化测试与明确的机器人流量，禁止事后按结果随意剔除失败用户。

| 指标 | 分子 / 分母与粒度 | 数据来源与主要限制 |
| --- | --- | --- |
| 上传完成率 | 同一上传尝试在 30 分钟内得到后端可持久化图片确认的次数 / 已满 30 分钟观察窗的上传尝试次数 | 客户端选择有效文件后记录 `upload_started`，服务端确认 `upload_completed`，用 `attempt_id` 配对去重；客户端启动事件丢失需单列，不能把无配对成功强塞入分子 |
| 生成成功率 | 提交后 24 小时内得到可用风格图及首次可播放动画的完整创建次数 / 已满 24 小时观察窗的服务端已接受完整创建次数 | 新建 `creation_id` 串联 extract/generate/animate；不能直接用三个 job 的平均成功率。预算拦截未被接受的请求单列；只完成图像不算完整成功，迟到完成另列 |
| 桌宠启动率 | 首次获得可用动画后 24 小时内收到 Electron 已解码并开始播放确认的用户 / 已满该观察窗、在 Windows 上获得可用动画的用户 | 网页发起调用、下载、生成成功均不是实际启动；按账户去重，以一次性启动票据关联。无法识别系统或没有桌面回传的用户标注覆盖缺口 |
| 次日回访率 | 首次成功桌宠播放后第 24–48 小时内有主动网页使用或桌宠交互的用户 / 已满 48 小时观察窗的首次激活用户 | 页面真正可见且有主动行为，或桌宠真实交互；后台心跳和自动播放不计回访。离线未回传标为观测缺口，不能断言流失 |
| 分享率 | 在已满 7 天观察窗的激活用户中，7 天内完成分享动作的去重用户 / 同批次激活用户 | 原生分享 API 成功或复制成功只是“分享动作代理指标”，不能证明发给别人；取消不算，接收方打开另列；分享必须用户主动授权，不能把私有宠物素材公开来凑指标 |
| 每活跃用户成本 | 周期内全部 AI 已结算成本（含失败/重试）/ 同期有效活跃用户数；另列全部服务成本/活跃用户 | 费用账本 + 供应商账单 + 云账单。预估与已结算分开显示，未知费用标注；不只统计成功调用，云资源按期间摊销，不拿内部 credits 冒充人民币 |

安全与数据质量：事件采用幂等 ID、服务端接收时间及有限枚举；不记录原图、宠物描述、邮箱、密码、完整 IP 或浏览器指纹到分析表。客户端事件可能被伪造，关键成果以服务端和受限桌面回执为证据。明确披露遥测范围、保留期限和退出机制，离线补传需要去重与时钟校验。

不预设“某个留存百分比即商业成功”。先积累完整观察窗，报告用户数、分群与不确定性；D1 只能证明短期回来，不等于愿意支付。连续成熟批次有真实回访、启动覆盖可信、成本可控后，再由维护者确认是否试验收费；不自动接入支付。

## 域名怎么选、谁负责什么

- 域名是地址，云服务器是运行程序的机器，DNS 把地址指向机器，HTTPS 保护连接；换机房通常不用更换域名。
- 初期一个主域名即可：根地址放网页与 API，`/en` 路径并非切换语言的必要条件；当前采用 cookie 记忆语言。`www` 可以指向同一站点，无需买第二个域名。
- 注册人应是用户本人/其主体。账号实名与域名持有者信息不是同一件事；认证资料只在阿里云官方控制台由用户提交，不交给开发者或聊天工具。[阿里云注册流程](https://help.aliyun.com/zh/dws/user-guide/how-to-register-a-domain-name)、[持有者说明](https://help.aliyun.com/zh/dws/getting-started/quickly-register-a-new-domain-name)
- 待用户选名称后查注册状态、普通价/溢价、首年与续费价格、转入转出条件。后缀可为 `.app` / `.pet`，但不为保留名字突破每年 300 元上限。查询可用不是保留成功。
- 自动续费是后续单独授权的扣款设置；先提供到期提醒和续费金额，不自行开启。HTTPS 与发信域名验证属于部署工作，不代表需要购买一整套企业邮箱。
- 注册验证/找回密码使用事务邮件服务，需 SPF、DKIM、DMARC 等配置及真实收信验证；域名买好不等于邮件能送达。
