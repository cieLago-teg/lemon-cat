# 原图参考生成与身份质检

本次 1A：原图先保存为私有素材，Qwen Image Edit 直接接收原图与风格指令；Qwen VL 对照原图和候选图，只有通过的形象可进入视频阶段。

## 规则

- `pass` 必须有至少两项具体相符特征、没有冲突。`fail`、`uncertain`、空响应、坏 JSON、网络错误都不放行。
- 判断允许画风和姿态变化；同品种或同颜色不足以证明同一只。极简风格无法识别时会被拦截。
- 质检记录存入 `identity_checks`，绑定用户、生成任务、原图、结果素材、模型与策略版本。请求或档案中的 `passed` 不具有授权作用。
- 视频入口和 worker 都检查通过记录，不能另外传未验证参考图。桌宠下载也检查来源；旧离线缓存不会自动恢复。
- 旧素材保留，但没有质检记录的图/视频不得进入新的视频或桌宠交付流程。
- 质检异常进入待核对，保留候选素材，不自动重生图；内测额度沿用待核对保留规则。
- 一部分风格失败时，只返回通过的结果，并提示被拦截的风格及原因。全部失败则任务待核对。

## 启动与配置

执行 `npm run migrate` 创建质检表，然后重启 `npm run dev` 以加载新 worker。

`BAILIAN_PET_IMAGE_MODEL` 默认 `qwen-image-edit-plus-2025-12-15`，独立于旧的文生图配置，避免误用文生图模型；`BAILIAN_IDENTITY_MODEL` 默认 `qwen3-vl-plus`。仍使用既有国内百炼密钥与端点。

协议依据：https://help.aliyun.com/zh/model-studio/qwen-image-edit-api

## 验证

`npm run check`：请求实际携带原图、双图顺序、质检解析与非成功结果隐藏。

`npm run check:service`：数据库记录、用户隔离、替换参考图拦截、质检失败状态。

`npm run check:http`：真实本地 API，不调用付费模型；验证伪造 passed、未质检视频、替换参考图与用户隔离。

`npm run check:desktop`：使用合成透明视频，实际验证 Electron 在线播放、合格缓存离线恢复及旧缓存拦截；不代表真实宠物模型效果。

`npm run verify:identity -- "D:\path\original.jpg"`：真实模型，四种内置风格各一次生图和一次质检；第三个参数 `0` 至 `3` 可限定一种。输出保存在被 Git 忽略的 `data/evaluations/identity-*`，包含原图、结果图及 JSON 报告。该命令会产生供应商调用费用，不自动重试生图。

代码与防绕过测试不等同于真实模型效果验收；必须查看实际原图/风格图以及对应报告。单张图和 VL 判断无法保证生物身份绝对准确，也不能证明所有未来图片、任意风格都必然通过。

当前默认本地素材存储可用于 Qwen 双图验收，但实际 Wan 视频仍需要现有流程要求的、供应商可访问的 S3 兼容私有存储。合成视频测试不证明这段外部链路已配置成功。
