# 原图参考生成与用户判断

当前 1A 主流程不再用 VL 对生成结果做身份裁判。Qwen Image Edit 直接接收用户原图和风格指令，生成结果全部返回给用户，由用户选择“像不像自己的宠物”。

## 为什么不做模型拦截

- 风格化的目标就是改变画风、姿态和细节表达，VL 的 `uncertain` 不能等价于“不是同一只宠物”。
- 现有流程已经先用 VL 提取特征标签，再让用户删除、修改和补充；生成前还可以填写宠物独有细节和故事。
- 用户是最终验收者，模型负责提取信息和执行创作，不负责替用户做审美和身份判断。

## 当前约束

- 原图会被保存为用户私有素材，并作为 Qwen Image Edit 的参考图。
- 只有用户自己的图片和视频可以进入后续接口；视频必须使用当前选中的形象，不能替换成另一张参考图。
- 生成结果不会因为 VL 的二次判断被过滤；失败只来自模型调用、素材保存、抠像或明确的请求错误。
- `identity_checks` 表仍保留在已有数据库中，作为历史版本数据兼容，不再写入或作为任何接口门禁。

## 验证

`npm run check`：验证原图随请求进入 Qwen Image Edit，以及生成结果可完整返回。

`npm run check:service`：验证任务持久化、用户隔离和重启恢复。

`npm run check:http`：真实本地 API，不调用付费模型；验证没有客户端伪造 `identity.passed` 的必要，自己的形象可以直接提交动画。

`npm run check:desktop`：使用合成透明视频，验证 Electron 在线播放、离线缓存恢复和用户素材归属。

真实模型验收建议由用户手动选择一张高质量原图，观察四种风格后自行决定哪些进入视频阶段；这样不会因为风格化导致的 VL 误判浪费生成结果。
