# 2026-09-09 画风趋同修正

## 问题与改动

真实任务的四张图分别调用了 `qwen-image-edit-plus-2025-12-15`，不是前端复用图片。旧水墨模板强调 Q 版、干净线条和淡彩，但缺少墨色浓淡、断续轮廓、枯笔飞白等可见要求；共用背景限制也容易被解释为对整个画面的材质限制。

- 水墨明确毛笔提按、断续轮廓、主体内部墨色浓淡、局部飞白，保留宠物标志花纹与颜色关系。
- 画风要求提前，原图用于身份，允许按风格概括细节和调整比例；纯白限制明确只作用于背景。
- 删除默认“和纸拼贴绘本风”，新任务生成水墨、贴纸、像素三张。已有作品及其动画兼容逻辑保留。
- 贴纸与像素模板沿用原有写法。中间版加强贴纸措辞出现重复宠物，已回退这些措辞。
- 特征模型仍为本机配置的 Qwen3.7 Flash；不恢复 VL 生成审核，故事仍不参与生成。

阿里云[图像编辑 API 文档](https://help.aliyun.com/zh/model-studio/qwen-image-edit-api)规定当前 Plus 正向提示词上限为 800 Token，超出自动截断。此次压缩重复约束，但字符数不等于 Token 数，未实现供应商 tokenizer 校验，特别长的主人补充仍需注意此限制。

## 复现

先 `npm run worker:build`。下列命令仅创建本地报告，不调用付费模型；指定本机存在的生成任务 ID：

```powershell
node --env-file-if-exists=.env.local --env-file-if-exists=.env.1a.local scripts/model-lab.cjs --job <任务ID> --baseline 4896480
```

`--run` 才发起付费调用。默认风格索引随当前目录生成；`--styles 0` 只测水墨。历史对照按风格名匹配，避免删除和纸后错把贴纸与和纸比较。每项失败留存错误，不自动重试。

网页复测：打开 http://127.0.0.1:3000/create 重新上传并生成。已完成任务的旧图片不会因改提示词自动改变。
