# 本地开发者入口

本地开发时不需要先注册账号或填写内测邀请码。

1. 启动 `npm run dev`。
2. 打开 `http://127.0.0.1:3000/developer`，或在登录页点击“我是开发者：免注册进入本地测试”。
3. 页面会创建一个仅限本机的 `developer@lemoncat.local` 会话，然后可以直接进入开始创建、我的宠物、生成任务和档案列表。

这个入口只在 `localhost`、`127.0.0.1` 或 `::1` 且非生产环境时存在。它使用独立的本地开发账号，不会绕过正式环境的登录、邀请码和用户隔离；正式部署前删除该路由与页面入口即可。

本地开发账号默认有 100 个内部测试额度单位，可通过 `DEVELOPER_INITIAL_CREDITS` 调整。实际调用 Qwen/Wan 仍可能产生供应商费用，测试前请确认本地密钥和预算。
